# Glow & Grow Studio

Glow & Grow Studio is a personal brand website, beauty and wellness product curation platform, community hub, and mini app studio.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Project name: `glow-grow-studio`

Deploy with:

```bash
npm run deploy
```

After deployment, add your domain in Cloudflare Pages under **Custom domains**.
